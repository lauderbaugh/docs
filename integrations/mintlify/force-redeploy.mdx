---

\## Force Redeploying Existing Content Once a draft reaches the \*\*Deployed\*\* status, the standard deploy actions skip it to prevent accidental overwrites. You can override this behaviour when you need to push content again — for example after editing a draft directly or after updating your deployment configuration. ### Redeploying a Single Section To redeploy one section: 1. Select the deployed draft in the section tree. 2. The deploy button changes to indicate a redeploy action is available. 3. Confirm the action. The integration pushes the current draft content to your Mintlify repository, overwriting the existing file. ### Redeploying All Sections To push every section — including already-deployed ones — navigate to your repository settings and select \*\*Force Deploy All\*\*. This triggers a bulk redeploy of all sections for the configured doc type, regardless of their current status. Use this option with care. It overwrites all existing files in your target repository with the current draft content.
