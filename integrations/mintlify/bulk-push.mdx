title: "Bulk Push to Mintlify"
---

\## Bulk Push to Mintlify You can deploy multiple approved drafts to your Mintlify site in a single operation. The bulk push processes each draft in sequence and then writes all navigation changes to \`docs.json\` once at the end. ### How Bulk Push Works When you trigger a bulk deployment, the integration: 1. Iterates over each draft node in the batch. 2. Converts and pushes each MDX file to the docs repository. 3. Collects all navigation entries that need to be added or verified. 4. Writes a single batched update to \`docs.json\`, covering every draft in the batch. Batching the \`docs.json\` update prevents write conflicts that would occur if each draft updated the navigation file independently. ### Result Reporting After the bulk push completes, the system returns a result for each node in the batch. Each result indicates whether the push succeeded and, if it failed, what error occurred. Successful pushes include the commit SHA of the file that was written. ### Partial Failures If one draft in the batch fails to push, the integration continues processing the remaining drafts. You will see individual success and failure statuses for each node in the batch result, so you can identify and retry only the drafts that did not deploy.
