\## File Path Resolution When the Mintlify integration writes an MDX file, it derives the file path automatically from the doc type and section path. You do not need to specify paths manually. ### How Paths Are Resolved The integration combines three pieces of information to build the full file path: - \*\*Doc type\*\* — determines the top-level folder. User-facing docs go into \`guides/\`, internal docs into \`internal/\`, and API docs into \`api-reference/\`. - \*\*Section path\*\* — the hierarchical path of the section (for example, \`authentication/overview\`). - \*\*Base path\*\* — the root folder inside your repository where all docs are stored, as set in your deployment target configuration. For example, a user-facing section with the path \`authentication/overview\` and a base path of \`docs\` is written to \`docs/guides/authentication/overview.mdx\`. ### Navigation Path Resolution The path stored in \`docs.json\` navigation is derived separately from the full file path. It omits the base path prefix and file extension, so Mintlify can resolve it correctly when rendering your site. ### docs.json Location The integration looks for \`docs.json\` at a configurable path inside your repository. If you store your navigation file somewhere other than the repository root, you can override the default path in your deployment target settings.
