\## Rediscovering Your Mintlify Structure If your Mintlify site already has existing content, you can run a rediscovery to import your current navigation structure rather than building a documentation skeleton from scratch. ### What Rediscovery Does Rediscovery reads your \`docs.json\` file and extracts the existing page structure — tabs, groups, and page paths. It then proposes this structure as your documentation skeleton so that the system's section tree matches what is already published. ### When to Use Rediscovery Use rediscovery when: - You are connecting a repository that already has a Mintlify docs site. - You have added pages to your docs site manually and want the system to recognise them. - You want to reset your skeleton after making structural changes directly in \`docs.json\`. ### Running Rediscovery 1. Navigate to your repository settings and open the \*\*Onboarding\*\* panel. 2. Select \*\*Rediscover\*\* to scan your existing \`docs.json\`. 3. Review the proposed skeleton and deselect any pages you do not want to track. 4. Confirm the skeleton to save it. After rediscovery completes, new drafts are matched to the imported sections automatically.
