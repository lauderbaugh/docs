\## MDX File Format The Mintlify integration converts your approved draft content into MDX files before pushing them to your docs repository. Understanding the output format helps you predict what your deployed pages will look like. ### Frontmatter Every generated MDX file includes a YAML frontmatter block at the top of the file. The frontmatter contains: - \*\*title\*\* — the section heading from your draft. - \*\*description\*\* — a short description derived from the draft content. Mintlify uses these fields to populate page titles, meta tags, and navigation labels. ### Body Content The body of the MDX file is your draft content converted from HTML or rich text to Markdown. The integration uses a Markdown serialiser to handle headings, paragraphs, bold, italic, inline code, lists, and links. Elements that cannot be represented in Markdown are omitted. ### Editing Generated Files You can edit the generated MDX files directly in your docs repository. The next time you deploy a new draft for the same section, the integration overwrites the file with the newly generated content. If you want to preserve manual edits, make those changes in the draft editor before approving.
