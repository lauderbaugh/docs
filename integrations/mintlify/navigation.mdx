\## Managing Mintlify Navigation Every time you deploy a draft to Mintlify, the integration updates your \`docs.json\` file to ensure the new page appears in your site's navigation. You do not need to edit \`docs.json\` manually. ### Navigation Groups Pages are organised into navigation groups based on their doc type: - \*\*User-Facing\*\* docs are placed in the \_Guides\_ group. - \*\*Internal\*\* docs are placed in the \_Internal\_ group. - \*\*API\*\* docs are placed in the \_API Reference\_ group. If a matching group does not exist in your \`docs.json\`, the integration creates it automatically. ### File Path Resolution The integration derives the file path for each MDX file from the doc type and section path. For example, a user-facing page with the section path \`authentication/overview\` is written to \`guides/authentication/overview.mdx\` inside your configured base path. ### Batch Navigation Updates When you deploy multiple drafts at once, the integration batches the \`docs.json\` navigation updates into a single operation rather than writing the file once per draft. This prevents conflicts that would otherwise occur when several pages are deployed in quick succession. If the update fails due to a concurrent write, the integration retries automatically up to four times before reporting an error. ### docs.json Format Compatibility The integration supports both the current object-based \`docs.json\` format used by Mintlify v4 and the older array-based navigation format used by earlier versions. You do not need to migrate your configuration — the integration detects the format automatically.
