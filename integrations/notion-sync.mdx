\## Syncing Content to Notion You can push your documentation content directly to a Notion workspace using the Notion integration. Once configured, the integration converts your content to Markdown-compatible rich text and creates or updates pages in Notion automatically. ### How It Works When you trigger a sync, the integration: 1. Fetches all existing blocks from the target Notion page. 2. Computes a content hash to detect whether the page has changed since your last sync. 3. Converts your content — including headings, paragraphs, and rich text formatting — into Notion-compatible blocks. 4. Pushes the converted blocks to Notion, creating or updating the page as needed. Because the integration checks the content hash before writing, it skips pages that are already up to date. This keeps your Notion workspace consistent without creating duplicate updates. ### Supported Formatting The integration preserves the following formatting when it converts content to Notion blocks: - \*\*Headings\*\* — H1, H2, and H3 levels map to their corresponding Notion heading block types. - \*\*Rich text\*\* — Bold, italic, inline code, and plain text are converted to Notion rich text annotations. - \*\*Paragraphs\*\* — Standard paragraph blocks are carried over directly. If your content includes unsupported block types, the integration skips them and continues processing the rest of the page. ### Setting Up the Integration To connect your workspace to Notion: 1. Navigate to \*\*Integrations\*\* in your settings. 2. Select \*\*Notion\*\* and enter your Notion API token. 3. Specify the target Notion page ID where you want content to appear. 4. Save your settings and trigger a sync to verify the connection. You need a Notion integration token with read and write access to the target page. If the token lacks the necessary permissions, the sync will fail and display an error. ### Scaffolding New Sections When the agent proposes a new documentation section, the Notion integration can scaffold it automatically. Scaffolding creates a new Notion page under the specified parent page and returns its page ID so future deployments know where to push content. If no parent page is specified, the integration creates the new page at the top level of your connected workspace. ### Triggering a Sync You can trigger a Notion sync manually from the deployment panel. Select the draft you want to deploy, choose \*\*Deploy\*\*, and confirm. The integration fetches the latest content, converts it, and writes it to the target Notion page. To re-index an existing Notion page without pushing new content, use \*\*Rescan\*\* from your repository settings.
