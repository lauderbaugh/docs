\## Managing Documentation Drafts When the documentation agent processes a pull request, it generates drafts organized by documentation type and section. You can review, edit, approve, reject, regenerate, and deploy each draft individually or in bulk. ### Understanding Draft Status Each draft displays a status badge so you can see its current state at a glance: - \*\*Pending\*\* — The draft is waiting for your review. - \*\*In Review\*\* — The draft is actively being reviewed. - \*\*Approved\*\* — You have approved the draft and it is ready to deploy. - \*\*Rejected\*\* — You have rejected the draft. You can regenerate it if needed. - \*\*Failed\*\* — The deployment attempt encountered an error. - \*\*Not Applicable\*\* — The agent determined this section does not require documentation for this change. - \*\*Deployed\*\* — The draft has been published to your documentation. ### Navigating the Section Tree The review page displays a section tree on the left side of the screen. Each node in the tree represents a documentation section. Select a node to open that section's draft in the editor on the right. The tree groups sections by documentation type. Within each type, sections nest according to your documentation hierarchy. Sections with a pending draft are highlighted so you can find them quickly. ### Proposed Sections In addition to updates to existing sections, the agent may propose entirely new sections it believes your documentation is missing. Proposed sections appear in the tree alongside regular drafts and are clearly labelled. You can: - \*\*Accept a proposal\*\* — approve and deploy it like any other draft. - \*\*Change the parent\*\* — reassign a proposed section to a different parent node before approving. - \*\*Reject a proposal\*\* — dismiss it if you do not want the new section created. ### Reviewing and Editing a Draft To review a draft: 1. Select a section in the tree. 2. Read the generated content in the editor panel. 3. Make any edits directly in the editor. 4. Approve, reject, or deploy the draft using the action bar. ### Real-Time Updates The review page listens for real-time events. When the agent finishes processing a draft or a deployment completes, the page updates automatically — you do not need to refresh.
