\## Changing a Proposal's Parent Section When the agent proposes a new documentation section, it suggests a location in your documentation hierarchy. If the suggested location is not right, you can reassign the proposal to a different parent before approving it. ### How to Change the Parent 1. Select the proposed section in the tree. 2. Open the parent selector in the editor panel. 3. Choose a new parent from the list of existing sections. 4. Save the change. The proposal's section path updates automatically to reflect the new parent. The content the agent generated is preserved — only the location changes. ### Why This Matters The parent you choose determines where the new page is created in your documentation target. If you deploy a proposal under the wrong parent, it will appear in the wrong place in your site's navigation. Reviewing and correcting the parent before deploying avoids having to move or delete pages after the fact. ### Constraints - You can only assign a proposal to an existing confirmed section as its parent. You cannot nest a proposal under another proposal. - Changing the parent does not affect the draft's approval status — if the draft was already approved, it remains approved at the new location.
