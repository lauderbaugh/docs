\## Interacting with the Agent The draft review interface includes a built-in interaction panel that lets you communicate directly with the documentation agent. You can ask the agent to revise a draft, give it specific instructions, or revert a revision if you change your mind. ### Requesting a Revision To ask the agent to revise a draft: 1. Select the draft in the section tree. 2. Open the agent interaction panel on the right side of the editor. 3. Type your instructions — for example, "Make this section more concise" or "Add an example for the authentication flow". 4. Submit your request. The agent rewrites the draft and the editor updates with the revised content. You can continue sending revision requests until the content meets your expectations. ### Reverting a Revision If you are not satisfied with a revision, you can revert to the previous version. Select \*\*Revert\*\* in the interaction panel to restore the draft to the content it had before the last agent revision. ### Regenerating from a Commit For pull requests that have new commits after the initial draft was generated, you can trigger a full regeneration. Select \*\*Regenerate\*\* to ask the agent to re-evaluate the latest code changes and produce a fresh draft. This is different from a revision — regeneration re-reads the source code, while a revision only rewrites the existing draft content based on your instructions.
