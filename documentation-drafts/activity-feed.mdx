\## Activity Feed The activity feed gives you an overview of every pull request the documentation agent has processed. Use it to track which PRs have pending drafts, which have been fully deployed, and which encountered errors. ### Reading the Feed Each row in the activity feed represents one pull request. You can see: - The pull request title and a relative timestamp showing when it was last updated. - A status dot indicating the overall state of the drafts for that PR. - The number of drafts generated and their breakdown by status. ### Status Filters Use the filter tabs at the top of the feed to narrow the list: - \*\*All\*\* — shows every processed pull request. - \*\*Pending\*\* — shows PRs that have drafts still awaiting review or approval. - \*\*Deployed\*\* — shows PRs where all applicable drafts have been published. - \*\*No updates\*\* — shows PRs that produced no applicable drafts. - \*\*Failed\*\* — shows PRs where one or more deployments failed. ### Pagination The feed paginates automatically. Use the page controls at the bottom to move through older activity. The URL updates with the current page and filter state, so you can bookmark or share a specific view. ### Real-Time Updates The feed listens for real-time events over a persistent connection. When a new pull request is processed or a draft status changes, the page updates automatically. If the connection drops — for example due to a network interruption — the page reconnects automatically. It waits 1 second before the first retry and increases the wait time with each subsequent attempt, up to a maximum of 30 seconds, then resets once the connection is restored.
