\## Monitoring Activity with the PR Activity Feed The activity feed gives you a chronological view of documentation events across all pull requests. Use it to track which PRs have pending drafts, which have been deployed, and which encountered errors. ### Filtering the Feed You can filter the activity feed by status to focus on the events that need your attention: - \*\*All\*\* — shows every PR the agent has processed. - \*\*Pending\*\* — shows PRs that have drafts waiting for review or approval. - \*\*Deployed\*\* — shows PRs whose drafts have been fully deployed. - \*\*No updates\*\* — shows PRs where the agent determined no documentation changes were needed. - \*\*Failed\*\* — shows PRs where the agent encountered an error during processing. Select a filter tab at the top of the activity feed to apply it. The feed reloads automatically when you switch tabs. ### Pagination The activity feed loads one page of results at a time. Use the navigation controls at the bottom of the feed to move between pages. The current page is reflected in the URL, so you can bookmark or share a specific page of results. ### Status Indicators Each row in the feed shows a coloured indicator dot that reflects the overall status of the PR's drafts: - A \*\*green\*\* dot means all drafts for that PR have been deployed. - A \*\*yellow\*\* dot means some drafts are still pending. - A \*\*red\*\* dot means one or more drafts failed. - A \*\*gray\*\* dot means no documentation updates were needed.
