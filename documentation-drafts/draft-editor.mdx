\## Using the Draft Editor The draft editor opens on the right side of the review page when you select a section in the tree. It shows the generated draft content and lets you edit, approve, reject, or deploy that section without leaving the page. ### Editing Content You can type directly in the editor to modify the draft before approving it. Changes you make are saved locally and included when you approve or deploy the draft. To discard your edits, regenerate the draft. ### Editor States The editor tracks its own busy state to prevent conflicting actions. When the editor is busy — for example, while the agent is generating a revision — action buttons are disabled until the operation completes. The busy indicator appears at the top of the editor panel. ### Keyboard and Toolbar Actions The editor toolbar gives you quick access to the most common actions for the selected draft: - \*\*Approve\*\* — marks the draft as approved. - \*\*Reject\*\* — marks the draft as rejected. - \*\*Regenerate\*\* — asks the agent to produce a new draft for this section. - \*\*Deploy\*\* — publishes the draft to your documentation target (available once the draft is approved). ### Realtime Updates The review page listens for realtime events from the server. If the agent finishes processing a draft while you have the page open, the editor updates automatically without requiring a page reload.
