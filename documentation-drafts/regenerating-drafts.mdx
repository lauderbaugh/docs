\## Regenerating a Draft If you are not satisfied with a generated draft — or if you rejected it and want to try again — you can ask the agent to regenerate it. Regeneration sends the same code change back through the agent and replaces the existing draft content with a fresh result. ### When to Regenerate Consider regenerating a draft when: - The generated content is inaccurate or misses important context. - You have updated your agent directions and want to apply the new instructions to an existing draft. - You rejected a draft but now want a new version without reverting the rejection manually. ### How to Regenerate 1. Select the section you want to regenerate in the section tree. 2. Select \*\*Regenerate\*\* from the section actions. 3. Wait for the agent to finish. The editor panel shows a loading state while the new draft is being generated. 4. Review the updated content and approve or edit it as needed. ### Agent Revisions Instead of a full regeneration, you can ask the agent to revise specific parts of the current draft. Use the revision input in the editor panel to describe what you want changed. The agent updates only the parts of the draft that match your instructions, preserving the rest of the content.
