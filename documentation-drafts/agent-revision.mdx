\## Requesting an Agent Revision If the generated draft content does not meet your expectations, you can ask the agent to revise it. An agent revision rewrites the draft content based on the current state of the code change and any agent direction rules you have configured. ### How to Request a Revision 1. Open the draft you want to revise by selecting its section in the tree. 2. Select \*\*Regenerate\*\* in the action bar. 3. The agent processes the request and replaces the draft content with a new version. You do not need to reject a draft before regenerating it. You can regenerate a draft at any stage as long as it has not been deployed. ### How Revisions Work When you request a revision, the system: 1. Queues a regeneration job for the selected draft. 2. The agent re-evaluates the code change, your agent direction rules, and the existing documentation structure. 3. The new content replaces the previous draft. The draft status resets to \*\*Draft\*\*. ### Editing Manually vs. Agent Revision You can also edit draft content directly in the editor without requesting an agent revision. Manual edits give you precise control and take effect immediately when you save. Use manual editing for minor corrections and agent revision when you want the agent to substantially rewrite the section. ### Real-Time Updates The review page maintains a live connection to the server using a reconnecting event stream. When an agent revision completes, the editor automatically updates with the new content — you do not need to refresh the page. If the connection drops, the page reconnects automatically using an exponential backoff strategy, starting at 1 second and capping at 30 seconds.
