\## Requesting Agent Revisions While reviewing a draft in the editor, you can ask the documentation agent to revise the content based on your instructions without leaving the review page. Agent revisions let you refine drafts quickly without having to regenerate from scratch. ### How to Request a Revision 1. Open a draft in the editor by selecting it in the section tree. 2. Use the revision input to describe the changes you want — for example, "shorten this section" or "add an example for the configuration field". 3. Submit your instructions. The agent processes your request and applies the revised content directly to the editor. 4. Review the updated content. If you are happy with the result, save and approve as usual. If not, you can request another revision or edit the content manually. ### What the Agent Can Revise You can ask the agent to: - Shorten or expand a section. - Rewrite content in a different tone or style. - Add, remove, or reorganise information within the section. - Fix factual inaccuracies you have spotted. The agent uses the same underlying context as the original draft — including the code diff and your configured agent directions — so its revisions stay consistent with the rest of your documentation. ### Saving After a Revision Revisions are applied to the editor immediately but are not saved automatically. Select \*\*Save\*\* to persist the revised content before approving or deploying the draft.
