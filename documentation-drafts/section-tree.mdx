\## The Section Tree The section tree is the left-hand panel on the pull request review page. It shows every documentation section the agent evaluated for this pull request, organised by documentation type and hierarchy. ### How the Tree Is Built The tree combines two sources of information: - \*\*Confirmed sections\*\* — sections that already exist in your documentation skeleton. - \*\*Draft details\*\* — the drafts the agent generated, including proposed new sections. Each node in the tree represents one section. Nodes nest to reflect your documentation hierarchy, with top-level pages at the root and sub-sections indented beneath them. ### Selecting a Section Select any node in the tree to open that section's draft in the editor panel on the right. The selected node is highlighted. The editor shows the draft content, status badge, and available actions for that section. ### Node Indicators Each node in the tree can display visual indicators: - A \*\*status badge\*\* showing the current draft status (Pending, Approved, Deployed, and so on). - A \*\*proposal label\*\* on sections the agent is suggesting should be added to your documentation. - A \*\*highlight\*\* on sections with drafts that need your attention. ### Proposed Sections in the Tree Proposed sections appear inline with confirmed sections. They are clearly labelled so you can distinguish them from updates to existing content. Select a proposed section to review the agent's reasoning and the suggested content, then approve, edit, or reject it. ### History Tab At the bottom of the tree you will find a \*\*History\*\* entry. Select it to open the event history for this pull request, which logs every agent action, deployment, and status change.
