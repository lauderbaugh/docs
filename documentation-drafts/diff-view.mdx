\## Comparing Draft Changes Before approving or deploying a draft, you can compare the proposed content against the baseline — the current published version of that section — to understand exactly what will change. ### Opening the Diff View When a draft has baseline content, a \*\*Show diff\*\* toggle appears in the editor toolbar. Select it to switch from the plain editor to a side-by-side diff. Text that the draft removes is highlighted in red, and text it adds is highlighted in green. Select \*\*Hide diff\*\* to return to the normal editor view. ### When Baseline Content Is Available Baseline content is available when: - The section has previously been deployed and the integration can read the current content from the target. - You have run a \*\*Rescan\*\* after making manual edits to the target platform. If no baseline exists — for example, for a brand-new proposed section — the diff view is not available and the toggle does not appear. ### Using the Change Summary Above the diff view, a summary bar shows a high-level description of what changed. Use this to get a quick sense of the scope of the update before reading the full diff.
