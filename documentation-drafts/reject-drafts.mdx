\## Rejecting Drafts If a generated draft is not useful or is incorrect, you can reject it. Rejecting removes the draft from your approval queue and signals to the system that the content should not be deployed. ### Rejecting a Single Section To reject the draft for the currently selected section: 1. Select the section in the tree. 2. Select \*\*Reject\*\* from the editor toolbar. 3. Confirm the action if prompted. The section's status updates to \*\*Rejected\*\*. You can regenerate a rejected draft at any time if you change your mind. ### Rejecting All Drafts To reject every pending draft for the pull request at once, select \*\*Reject all\*\* from the bulk actions menu. This marks all approvable drafts as rejected in a single operation. ### Rejecting a Proposed Section For sections the agent proposed as new additions to your documentation, rejection also removes the proposal from your skeleton. The section will not be created in your deployment target. If you want the section to exist but with different content, regenerate it instead of rejecting it.
