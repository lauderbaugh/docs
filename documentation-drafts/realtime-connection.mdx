\## Real-Time Draft Updates The draft review page maintains a persistent connection to the Syscribe server so that changes — new drafts, status transitions, deployment results — appear in your browser automatically without requiring a manual refresh. ### How the Connection Works When you open a pull request review page, the app opens a live event stream authenticated with your organisation token. The server sends events over this stream whenever something relevant changes for that PR. Events you may receive include: - \*\*Draft created\*\* — the agent has generated a new draft for a section. - \*\*Draft updated\*\* — the content or status of an existing draft has changed. - \*\*Draft failed\*\* — the agent encountered an error generating a draft. - \*\*Deployment updated\*\* — a deploy job has completed or failed. - \*\*Bootstrap started\*\* — the agent has started processing the pull request. - \*\*Commit processed\*\* — a new commit has been evaluated by the agent. ### Automatic Reconnection If the connection drops — for example due to a network interruption or a server restart — the page reconnects automatically. It waits \*\*1 second\*\* before the first retry. If that attempt also fails, the wait time increases with each retry up to a maximum of \*\*30 seconds\*\*. Once the connection is re-established successfully, the backoff timer resets to 1 second for any future disconnections. You do not need to take any action when a reconnection occurs. The page resumes receiving events as soon as the connection is restored. ### Token Refresh The event stream is authenticated using a short-lived organisation token. The app fetches a fresh token before each connection attempt, so your session stays authenticated even after long periods of inactivity.
