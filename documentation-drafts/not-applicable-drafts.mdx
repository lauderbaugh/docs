\## Not Applicable Drafts When the documentation agent evaluates a pull request, it may determine that certain documentation sections do not need an update for the changes introduced. In those cases, the agent marks the draft as \*\*Not Applicable\*\* rather than generating content. ### What Not Applicable Means A \*\*Not Applicable\*\* draft tells you that the agent reviewed the code change against that section and concluded that no documentation update is warranted. This is different from the agent failing to generate content — it is a deliberate signal that the section is already accurate or unaffected. Not Applicable drafts do not require any action from you. They appear in the section tree so you have full visibility into what the agent evaluated, but they are excluded from bulk approve, deploy, and reject actions. ### Reviewing a Not Applicable Draft If you disagree with the agent's assessment: 1. Select the Not Applicable section in the tree. 2. Review the agent's reasoning in the editor panel. 3. Select \*\*Regenerate\*\* to ask the agent to produce content for the section. After regeneration, the draft moves to \*\*Draft\*\* status and you can review, edit, and approve it as normal. ### Visibility in the Section Tree Not Applicable sections are visible in the tree but styled differently from sections with actionable drafts. They are not highlighted as requiring attention and are excluded from draft counts in the action bar.
