\## Filtering Drafts by Doc Type When you open a pull request review page, the drafts are organised by documentation type. You can switch between doc types to focus on one category at a time. ### Switching the Active Doc Type The doc type selector at the top of the review page lists every documentation type that has drafts for this pull request. Select a doc type to filter the section tree and action bar to show only drafts belonging to that type. When you switch doc types, the section tree resets to show the sections for the selected type. The first section with an actionable draft is selected automatically. ### Bulk Actions per Doc Type The action bar adapts to your active doc type. When you select \*\*Approve all\*\*, \*\*Deploy all\*\*, or \*\*Approve and Deploy all\*\*, the action applies only to drafts within the currently active doc type. To act across all doc types at once, use the \*\*All\*\* scope option. ### Doc Type Labels Doc types are displayed using human-readable labels throughout the interface: - \*\*User-Facing\*\* — documentation intended for your end users. - \*\*Internal\*\* — documentation for your own team. - \*\*API\*\* — reference documentation for your APIs. The label for each doc type appears in the section tree header, the action bar, and the confirmation modal so you always know which category you are acting on.
