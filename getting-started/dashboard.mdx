\## Dashboard The dashboard gives you a high-level view of your documentation system's activity. When you sign in, you land here first. ### Stats Cards The dashboard displays summary statistics that help you understand the current state of your documentation at a glance: - \*\*Pending drafts\*\* — the number of drafts waiting for your review across all repositories. - \*\*Deployed this week\*\* — the number of drafts published in the last seven days. - \*\*Repositories connected\*\* — the total number of repositories you have linked. Each card links to the relevant page so you can drill down into the details immediately. ### Getting Started If you have not yet connected a repository, the dashboard displays a getting-started prompt with a direct link to add your first repository. Once you connect a repository and the agent processes its first pull request, the stats cards populate automatically. ### Navigating the App Use the left-hand navigation to move between the main areas of the app: - \*\*Activity\*\* — the feed of processed pull requests and their draft statuses. - \*\*Drafts\*\* — a list of all drafts across all repositories, filterable by status. - \*\*Repositories\*\* — your connected repositories and their configuration. - \*\*Directions\*\* — agent direction rules. - \*\*History\*\* — a log of all system events. - \*\*Settings\*\* — team members, routing rules, and organisation settings.
